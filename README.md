# SoraChi

給日文零基礎的人：先學五十音和基礎句型，出發旅行前也能查常用的日文。

網站：https://sorachi.app/

直接入口：[五十音](https://sorachi.app/kana/) · [基礎句型](https://sorachi.app/grammar/) · [旅遊常用語](https://sorachi.app/travel/) · [基礎刷題](https://sorachi.app/drill/)。舊的 `#` 連結仍可使用，會自動切換成新網址。

原始碼、issues 與網站部署統一使用本 repo：`main` 開發，`gh-pages` 發佈到 https://sorachi.app/ 。舊 GitHub Pages 網址轉往正式站，不再維護獨立的資料匯出網站。

這是新手入門的雛形，不是完整的 N5／N4 教材。

## 可以做什麼

[小遊戲區](https://sorachi.app/games/) 集中平假名小填字、雲朵點餐店、雲朵行李箱與雲朵拍照散步；首頁有獨立插圖入口，課程原有捷徑仍保留。

- **五十音**：平假名、片假名各 104 個字（基本字、濁音・半濁音、拗音），另有促音、長音兩堂小課。每組先看卡片和記憶提示（基本字有字源、比一比、例子；濁音、半濁音、拗音說明讀音怎麼變），再做選擇題。學過的字可以用短輪複習，一輪最多 5 個字，答錯的字先練。
- **基礎句型**：48 課，分成「基本句子」「時間與數字」「動作與地點」「形容詞與連接」「動詞原形與て形」五個單元。照順序學，每課只用前面教過的詞；答錯時可以直接回看說明。例句附羅馬字、中文和語音。學完兩課以後，可以從學過的課挑幾題混在一起複習；進度會保存，但不改寫原課程成績。
- **旅遊常用語**：12 種情境、77 張卡，包含點餐與食材、便利商店問答、飯店需求、交通和購物；「演唱會・活動現場」是選用。先看關鍵字和意思，需要時再展開完整說法。可以收藏到「我的常用語」，查閱與收藏都不會計分。
- **雲朵拍照散步**：自由點公園的 5 個物件，認識單字、播放讀音，再拍進相簿；不依順序、不判錯，相簿可重看且不重複收錄。
- **雲朵行李箱**：從傘、水、帽子、手機、蘋果任選三件出門。能用物品，也能選樹蔭、涼亭或屋簷等做法，結尾留下實際旅行小記；附中文、羅馬音與逐詞播放，保存進度，不計分。
- **雲朵點餐店**：旅遊頁可進入，每輪接待 3 位客人，包含可自由搭配的開放訂單；也能自由調飲、收藏自己的小菜單再修改。使用本站咖啡、紅茶、冷熱與一到三份的詞，有中文、逐詞播放和羅馬音。兩種玩法各自保存進度，不計成績。
- **平假名小填字**：五十音頁可進入單人填字，共 8 盤、每盤 3 個本站例詞。看中文提示、選假名填格，可聽讀音、看羅馬字或提示一格；不計時、不計成績，會保存目前盤面。
- **使用習慣**：記住播放語速；首頁與句型頁可以接著上次的課學。
- **學習紀錄**：保留最近 200 次的完成紀錄，可以下載備份，也可以從備份還原進度、收藏與設定。

## 資料與隱私

- 不登入也能學；訪客進度存在目前瀏覽器。選用 Google 登入後，使用獨立帳號進度，可手動儲存／帶入雲端備份；不是自動同步。
- 登入不會自動搬入訪客資料或上傳進度。本站沒有加入分析追蹤；資料用途見[隱私政策](https://sorachi.app/privacy.html)。
- 換瀏覽器或清除網站資料前，先到「學習紀錄」下載備份。
- 字型使用 Google Fonts；語音是裝置內建的合成語音，聲音和品質依裝置而不同。

## 回報問題

各區頁首與頁尾都有「問題與建議」，不登入也能送出。站內回報不公開，聯絡方式選填，只附版本與教材識別碼，不附答案或學習紀錄。服務未連線時可改用 GitHub，送出前會提醒內容公開且需要 GitHub 帳號。
