# 首頁尺寸與共用介面檢查

基準：837bb8e。使用者希望一般筆電視窗可以看清楚四個入口，並檢查字太小、框太大、換行及互相遮擋。沿用已選的「快捷在上」與課程色塊分區。

## 調整

- 桌面首頁仍為 2×2 四個入口，角色與文字改為並排；壓低頁首、快捷列和卡片留白，保留原有文字大小及主要操作。1280×720 下，卡片由約 390px 降至 184–185px，四區底部由約 1137px 移到 667px。
- 900px 以上使用桌面卡片；中等寬度保留上下圖文但縮短插圖區；320px 改為角色與標題同列、說明和按鈕使用整行。沒有固定高度、裁切文字或縮放整個網站。
- 快捷列留在主入口上方。手機縮短重複的「隨機」文字，完整功能名稱仍保留在按鈕的無障礙名稱。
- 手機目錄的四個導覽入口改為 2×2；假名四選項同樣排成 2×2，避免三個加一個的孤立排列。
- 句型單元的手機隨機選課按鈕改為和標題並排，移除原本預留的 70px 頂部空白；單元說明仍使用完整寬度。
- 主要學習說明調至 15px，題目選項／旅遊詞的羅馬音調至 14px，假名表羅馬音調至 13px。保留日文、標音、中文的層次。
- 旅遊分類目錄改用較寬的桌面版面；個別旅遊卡維持閱讀寬度。縮減手機雙層框內距，允許詞語標籤換行。

## 驗證

- 隔離的 localhost:4217，不操作正式站的帳號或學習資料。
- 首頁、五十音、句型、假名字卡、句型教學、旅遊目錄、食物卡、刷題、設定、學習紀錄、帳號、回報、關於等 13 種頁面，在 320／390／768／1280px 共 52 組檢查：未見水平溢出、可見元素超出視窗或可互動按鈕互相遮擋。
- 另檢查全部 12 個旅遊分類、較長的て形與形容詞課，以及手機五個句型單元標題與隨機按鈕的相對位置。
- 首頁另量測 900／1024／1440px；900px 以上四個入口均在約 668px 內。手機允許正常上下捲動，不把全部內容硬塞一屏。
- 實際鍵盤從首頁進五十音隨機練習、作答後按 Enter 進下一題；從尚未展開的「動詞原形與て形」單元按隨機選課成功進課程。
- 現有三項流程測試原本依賴標籤中沒有任何 span 的 HTML 字串，本次改驗完整無障礙名稱；保留入口、進度、不記成績與返回等流程斷言。
- 教材檢查及全套 Node 測試須通過，再 prepare-release、同提交 CI、publish 與 verify-deploy。

## 限制

本輪是瀏覽器模擬寬度，未代替 Safari／iOS／Android、系統大字級或螢幕閱讀器實機測試。回報表單只檢查版面；正式 Turnstile 不允許 localhost，會出現網域驗證警告，沒有為了測試放寬設定。登入、回報送出與手動雲端備份的正式站驗收沿用前一批紀錄。
