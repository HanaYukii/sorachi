# 四個小遊戲審查（2026-11-01，#96）

基準：main `8db351f`。本輪只檢查四遊戲與共用入口；開始時沒有開啟中的 PR，沒有其他未提交變更。

## 玩法判斷

| 遊戲 | 零基礎與玩法判斷 | 本輪處理／限制 |
| --- | --- | --- |
| 平假名小填字 | 有交叉格、自己拼字及修改，與單題選擇有實際差別；原本只聽音、看羅馬字，完全不認假名的人會卡住。 | 「看單字與讀音」直接給完整假名，可以照著填，不自動填答、不記分。保留提示一格。 |
| 雲朵點餐店 | 本質仍是依需求配對，三組選擇容易像表單。 | 托盤實際呈現飲料、冰熱與份數；送錯可直接回需要修改的組別。仍是引導式點餐，沒有宣稱已變成經營遊戲。 |
| 雲朵行李箱 | 裝箱的同一批物品會出現在後續場景、角色會使用物品；但路線及答案固定，重玩變化有限。 | 修正手機裝滿／用錯物品的訊息位置。保留簡短引導；此輪不新增場景、背包系統或隨機考題。 |
| 雲朵拍照散步 | 能自由拍清單外的物件，沒有錯誤選項，偏探索／收藏。 | 移除重複反應訊息，修正拍照回饋焦點。固定 5 物件，收集完後可回看，長期重玩深度有限。 |

這是程式與介面走查，不是零基礎真人研究。下一步若要增加趣味，先觀察新手實際是否理解操作、願意重玩，再決定改玩法；不靠加計時、排名或換裝把同一套選擇題繼續包裝。公園物件目前是系統 emoji，各裝置畫風不同，不把這次檢查視為美術一致性已完成。

## 修正與清理

- 三遊戲共用 `gameMessage`：先寫入訊息再 focus／scroll；修正空 status 被 CSS 隱藏時焦點失敗。行李訊息移進場景，不再藏在長物品列表下方；拍照反應只出現一次。
- 點餐錯誤區增加「回去調整」；捲動避開手機上的客人卡。托盤顯示的是目前選擇，並非正解；讀取進度後仍一致。
- 320px 裝箱物品改為整顆按鈕拿出，避免按鈕內再塞按鈕般的視覺與換行撐高清單。短視窗關閉遊戲的 sticky 區，避免固定內容佔掉可操作空間。
- 刪除點餐未送餐分支中永遠不會用到的「已送餐」按鈕／disabled 判斷。
- 移除從未被樣式或事件使用的 `print-<id>` class，合併重複 `.crossword-current`、客人圖片樣式，移除被同斷點覆蓋的相簿 flex 規則。
- 沒有改 storage schema、清除標記、課程成績、舊備份或登入。填字繼續使用既有 `roman` 設定保存提示開關，舊進度可讀。

## 驗收

- 教材檢查、366 項 Node 測試、prepare-release 與 diff 檢查通過。
- 新回歸測試：托盤飲料／冰熱／份數與重載、空回饋先寫再聚焦、完整假名提示不會自動填答或算完成。
- 隔離 localhost:4243，320×568、375×667、1280×900：四遊戲畫面；填字第一盤通關及下一盤、點餐三客及重開、行李裝滿／拿出／三場景及回家、拍照五物件及相簿。完成或收藏後重新載入仍保留。
- 手機核對無水平溢出；點餐錯誤→調整冷熱時組別出現在客人卡下方；拍照回饋有焦點；主控台無 error。
- 全盤面的連通／交叉字和教材對照由既有自動測試覆蓋，沒有宣稱逐盤真人試玩。
- 未做 iOS／Android 實機、VoiceOver／TalkBack 或實際聲音品質驗收。未修改正式站使用者資料。
