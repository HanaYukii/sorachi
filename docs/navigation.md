# 頁面與返回規則

`navigation.js` 只負責路由名稱、區域及頁首呈現。app.js 仍管理 history.state 的來源，Study 仍管理教材／練習／旅遊搜尋。不要在頁首用 history.back() 取代明確目的地。

| 路由 | 類型／區域 | 返回／導覽 |
| --- | --- | --- |
| #home | 首頁 | 上方兩種隨機練習，固定三張角色入口；接續與進度在下面 |
| #kana、#grammar、#travel | 總覽／對應區域 | 回首頁，三區導覽標示目前區域 |
| #travel/favorites | 收藏／旅遊 | 回旅遊常用語，三區導覽標示旅遊 |
| #study/:id | 教學與課後練習／由課程決定 | 沿用來源回首頁或所屬列表，直接網址則回所屬列表；完成頁相同 |
| #kana-random、#grammar-random | 隨機練習 | 從列表進入則回列表，首頁或無來源則回首頁；另有明確字表／句型連結 |
| #kana-review、#grammar-review | 已學內容複習 | 沿用來源回首頁或所屬列表，直接網址回列表 |
| #travel/:id | 旅遊詳情 | 回原搜尋、收藏或分類；保留原有查詢、定位與焦點 |
| #lesson、#done | 三種文字入門 | 回首頁 |
| #history、#settings、#about | 工具／說明 | 回首頁，不單獨插入旅遊捷徑 |
| #feedback | 回報 | 專用返回動作，還原原頁與回報上下文；不自行送出 |
| 舊 #study/t-* | 相容轉址 | 保留到對應旅遊卡的轉址 |
| 找不到的 #study/*、#travel/* | 錯誤頁 | 顯示找不到頁面及明確入口；其他未知 hash 沿用回首頁規則 |

所有總覽導覽採一般連結，重載／上一頁／下一頁沿用 app.js 的既有 history 行為。課內翻卡及作答不增加 history。列表返回後重開原單元、聚焦原課程的行為仍由 route() 處理。

## 作答模式

| 模式 | 答錯後 | 下一題 | 保存與計分 |
| --- | --- | --- | --- |
| 句型／特殊音課後練習 | 顯示正解與讀音，提示選一次正確答案；可回看說明 | 選對後可按 | 接續可重載；第一次作答計分，重試不改寫 |
| 五十音課後練習 | 顯示字與讀音，輪末再考一次 | 首答後可按 | 接續可重載；只計第一次，輪末重考不改寫 |
| 五十音複習 | 首輪顯示正解；重考輪不提前公布答案 | 作答後可按 | 接續與錯字狀態保存，不新增課程成績 |
| 句型小複習 | 顯示正解、讀音與回看說明，提示選對後繼續 | 選對後可按 | 接續與錯題狀態保存，不新增課程成績 |
| 五十音／句型隨機 | 正誤與正解清楚標示，不要求重選 | 作答後可按 | 只留本頁這輪結果，重載重抽，不改課程成績／複習 |

`grammarFeedback()` 共用正解與讀音，`showFeedback()` 共用回饋顯示及必要捲動；各模式仍自行決定下一題與焦點時機。不要為共用 UI 合併不同保存或重考規則。讀屏實機驗證仍屬 #15／#73 的後續驗收。

## 完成頁

- 本輪結果與計分範圍先顯示；課後練習記第一次作答，隨機／複習不新增課程成績。
- 共用 `resultActions()`：來源返回是主要按鈕，下一課或再練一次是次要動作。有下一課時，重新練習收到「其他練習選項」，不另放第三個並列動作。
- 錯題相關課程收到「回看相關課程」，仍可展開並進入原課程。
- 列表、課程頁、下一課、相關課程及瀏覽器標題共用 `Content.displayTitle()`；儲存的課程 ID、revision 和歷史成績不因顯示名稱而改寫。
