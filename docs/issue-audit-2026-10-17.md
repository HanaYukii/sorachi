- **#68 ています、てもいいですか**
  - `g-te-iru` 分兩種：正在做（のんで います），以及做完後留下的狀態（よやくして います）。
  - 比較卡寫明「いま たべます」是現在就要吃，不是正在吃；〜て います「可以」說正在做，沒有教成一律是「正在」。
  - 予約しています 不誤譯：`g-te-iru/question/state` 的情境是飯店櫃檯，正解「我有預約」，「我正在預約」是錯誤選項。卡片和旅遊卡 `phrase/hotel/reservation` 都譯「我有預約」。
  - `g-te-mo-ii`：〜ても いいですか 和〜て ください 對照（做的人是誰）。回答教 はい、どうぞ，以及話沒說完的 すみません、ちょっと…；卡片說明這裡的 ちょっと 不是「一下」。のんでも 的 でも 註明不是「但是」。

    - 「問自己可不可以做」讀起來像自問，改成「問對方：我可以…嗎？」。

- **#67 だから、ので、けど**
  - `g-dakara`：だから 放在第二句開頭，から、ので 接在第一句後面，ので 比 から 委婉；第二句開頭的 から 是錯誤選項並說明原因。卡片提到對客人或長輩可以說 ですから。
  - `g-kedo`：けど 和 でも 意思一樣、位置不同；整理卡把學過的連接詞依位置分成兩組。
  - 題目給出原因／結果或優點／缺點的關係，讓學習者自己判斷方向。
  - 審查抓到並已改：けど 題原本同時放 から、ので 兩個同義的錯誤選項，不懂 けど 也能把兩個一起刪掉。改成兩選一（けど／から）；併句題改用「ちいさいですでも」這種位置錯誤。

- **#75 旅遊搜尋**
  - 旅遊首頁加搜尋框，比對卡片標題、關鍵字與讀音、中文意思、日文例句與羅馬字，也比對「店員可能會問」、延伸說法，以及情境的標題和中文說明。全形半形、大小寫、標點、片假名／平假名、臺／台、羅馬字長音（hoomu、homu）都先正規化；另有少量別名（寄物、洗手間、買單、打包、儲值、交通卡…）。

  - 整串找不到時拆成幾個詞：空格、標點、羅馬字和中文相接處都會拆（suica加值）。前後的客套話、請求和「…的日文／怎麼說」一個一個拆掉，剩下卡片裡有的詞就停（袋ください → 袋、謝謝的日文 → 謝謝、我要這個的日文 → 我要這個；熱的日文 → 熱的）；剩一個字時，要是某張卡的關鍵字才算（袋、水；那是什麼意思 → 找不到）。一口氣打的羅馬字也一樣（kippukudasai → kippu）。拆完還是沒有卡片有的中文兩個字兩個字試（西瓜卡加值、寄放行李箱），比兩個字長的別名先換掉再拆（塑膠袋要錢 → 袋子）。結尾是一個字的地點（駅、站、口、票、梯）時，那個字和它後面的字也試（新宿駅はどこですか → 駅、駅は）；請求後面的字只有和請求連起來是卡片裡的詞才試（我要這個日文 → 要這）。
  - 卡片要含比較少見的主題詞（不超過一成卡片有）才會列出（kippu wa doko → 車票）。客套話、請求（すみません、請問、ください、可以嗎）、助詞和常見詞（wa、desu、doko、onegaishimasu）只用來排序；單獨打的「日文」「怎麼說」完全不算（不好意思 日文 → 不好意思那張），但在詞裡面的照算（不會日文 → 聽不懂）。整串只有客套話和常見詞時，列出含最多這些詞的卡；問到卡片沒有的東西（有吸管嗎、有吹風機嗎、便利商店在哪、sutoroo arimasuka）就顯示找不到。排序：主題詞多、詞就是卡片關鍵字或在標題、詞少見、整串的詞多、情境名稱也相符（退房 行李 → 寄放行李；演唱會 飲料 → 演唱會的飲料費）。拆開比對時，三個字母以內的羅馬字要整個詞相符（iku 不會找到 ikura）。

  - 點結果會開到那張卡並取得焦點，上一頁回到原本的搜尋，焦點在剛才開的那一列。讀屏只念「找到 N 張卡」，不逐列念。日文輸入法組字時不打斷；按 Enter 移到結果標題（手機鍵盤會收起），輸入法確定選字的那個 Enter 不算（含 Safari 的送法）。搜尋字只在頁面記憶裡，不保存也不上傳。
