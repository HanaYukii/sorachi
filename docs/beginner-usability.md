# 新手試用觀察（#73）

狀態：已準備流程，尚未找真人試用。自動測試與桌面瀏覽器的手機尺寸檢查不算真人驗收。

請邀請 3 位幾乎沒學過日文的人，各試約 10–15 分鐘。不先示範操作；告訴對方「我們在測網站，不是在考你」。只記代號，不需要姓名或聯絡資料。

## 給試用者的任務

1. 你第一次學日文，請從首頁找到可以開始的地方，學第一組五十音，再試著做題。不懂的字可以找讀音或換一種記法。
2. 找到基礎句型，完成第一堂課。遇到答錯時，看看能不能找到說明。中途關閉分頁，再打開看看能否接著學。
3. 你在日本旅行，想請飯店寄放行李。找到可以說的詞，播放讀音，收藏它。回首頁後，再找到剛才收藏的內容。
4. 如果語音太快，試著調慢。重新整理後，看看是否保留了選擇。

不用逼對方完成所有任務。卡住時先問「你現在想找什麼？」；真的需要提示時，再給提示並記錄。

- 是否找到讀音、解說、接續和收藏：
- 提供了哪些提示：
- 最想先修的一件事：
