# 旅遊卡的官方來源

旅遊卡裡講到服務規定的句子，都依下列官方頁面核對（2026-10-16 讀取）。各業者規定不同，卡片只寫通則，並提醒以現場說明為準。規定改了就更新卡片和這份清單。

旅客自己就能說的詞句（〇〇まで、これ、入りますか？、財布をなくしました）屬於語言用法，不需要官方來源。
