# 五十音記憶提示審查（#35）

2026-10-17 依新需求重整：使用者幾乎零基礎，不預設認識日文詞。舊版「字形聯想＋聲音連結」兩套提示和「換個記法」都已拿掉，每張假名卡只有一個提示框。

## 原則

- **字源**：92 個基本假名逐字對照 Kotobank 上的三部辭典：デジタル大辞泉、精選版 日本国語大辞典、日本大百科全書（ニッポニカ）。另用三省堂大辞林的片假名對照表、日文維基百科交叉核對；維基百科不單獨決定任何一字。
  - 三部一致：直接寫。
  - 主說一致，但有辭典另列其他說法：畫面寫「一般認為」。
  - 漢字一致，只是取哪幾筆說法不同（メ、ヨ）：只寫漢字，不寫部位。
  - 沒有定論（つ、ツ、ん、ン）：畫面不寫字源。
  - 部件字「夕、木、厶、口、乚、丿」是依筆畫數推得，辭典只寫「前三筆」「最後四筆」等。
  - 平假名寫「草寫變來」，不用「草書」這類術語；異體字附台灣常用字形，例如「祢」（禰）。
- **比一比**：只放容易混淆的字，對照網站使用的 Noto Sans JP 字形逐一看過，寫清楚差在哪裡（點的位置、筆畫方向、有沒有小圈），不寫「多一條線」卻不說在哪。
- **例子**：每字一個常見詞，標出這次學的假名，附羅馬字與中文，可以播放。羅馬字和課程拼法相同（っ 重複子音、ー 重複母音），由測試自動比對。詞不用背，練習也不考；を 只當助詞，不放例子。
- **濁音、半濁音、拗音**：只說明和基本字的關係與讀音變化，不另寫字源。
- **舊資料**：舊版存的提示偏好（`preferences.kanaHints`，0／1）照樣保留、匯入，不再影響畫面，不會出現空白提示。

## 另有說法或未定的字

- さ／サ：さ←左 三部一致。サ：三部都以「散」的前3畫為主說，大辞林片假名表也列「散」；但日国另記「薩」的草字頭一說，依規則標 uncertain。若要顯示可寫「散（一說：薩）」。
- つ／ツ：三部都標為未定：大辞泉說可能出自「州」的略體，並在補說中說諸說未定（另有川・津・鬪等說）；日国：諸說、難以確定；ニッポニカ：出自「川」或「州」，未詳。大辞林片假名表列「州」；Wikipedia字源圖つ標「川」、ツ標「州」。建議不寫單一字源。
- は／ハ：は←波 三部一致。ハ：三部主說都是「八」；日国在括號內另列「半」的前2畫一說，依規則標 uncertain。若要顯示可寫「八（一說：半）」。
- ま／マ：ま←末 三部一致。マ：三部都說是「万」與「末」各自前2畫混合而成，但大辞泉・日国用傳聞語氣（といわれる／という）；Wikipedia字源圖只列「末」。「万」是「萬」的略體。
- め／メ：め←女、メ←女，字三部一致；但取哪2畫不一致：大辞泉・日国說最後2畫，ニッポニカ說前2畫（Wikipedia字源圖也標前2畫）。可只寫「女」不寫部位。
- よ／ヨ：字三部一致：「與」的略體「与」（繁中為「與」）。但ヨ取哪部分說法不一：大辞泉末3畫、日国末畫、ニッポニカ終畫；日国另記「出自『與』右上部件」一說。可只寫「与（與）」不寫部位。
- る／ル：る←留 三部一致（日国並列異體「畱」）。ル：大辞泉・ニッポニカ說「流」最後2畫；日国把它和「畱（留的異體）上部的草書」兩說並列，依規則標 uncertain。
- ろ／ロ：ろ←呂 三部一致，ロ的字「呂」也三部一致。但部位與語氣不一：大辞泉說前3畫（上方的口），日国只說出自呂，ニッポニカ寫「初畫」並用推測語氣（かと考えられている），依規則標 uncertain。
- わ／ワ：わ←和 三部一致。ワ：大辞泉主說「和」右旁「口」的草体，補說另有「表示『輪』的○分兩筆寫」一說；日国提到○說但認為出自「和」較妥當；ニッポニカ兩說並列。
- ん／ン：ん：大辞泉・日国並列「无」或「毛」的草体，ニッポニカ只寫「无」（无是「無」的古字）。ン：大辞泉・ニッポニカ推測出自表示撥音的符號（形似ㇾ/V），日国並列「爾」古體「尓」前2畫一說，並說不確定；Wikipedia字源圖採「尓」說。建議不寫單一漢字。
